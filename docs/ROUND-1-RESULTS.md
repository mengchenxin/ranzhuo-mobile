# 第一轮 AI 工程升级结果

## RAG

- 检索策略升级为 `BM25 + 向量 + 重排序`
- 文档切块参数为 420 字符窗口、84 字符重叠
- 返回 BM25、向量、混合和重排序分数
- 回答上下文携带 `[1]`、`[2]` 来源引用
- 支持兼容 OpenAI Embeddings 的外部向量接口
- 未配置向量接口时使用零成本本地降级方案

## 评测

当前确定性评测共 17 项：

- 3 个 Agent 工具契约与安全测试
- 1 个 RAG 入库检索闭环
- 12 个 RAG 金标检索测试
- 1 个真实模型套件占位

实测结果：

```text
通过率       17 / 17
Hit@3        100%
MRR          1.00
关键词覆盖    100%
平均耗时      约 5ms
```

金标评测覆盖角色档案、系统架构、长期记忆、Embedding、混合检索、模型选择和手机端密钥策略。

## 长期记忆

- 候选记忆经过确认和去重后写入
- 回答前根据当前问题计算记忆相关性
- 低于相关性阈值的记忆不会进入上下文
- 避免把所有长期记忆重复注入每次请求

## SQLite

- RAG 文档与知识块写入 SQLite
- 调用日志写入 SQLite
- 支持从旧 JSON 数据自动迁移
- 知识范围支持共享知识库和角色专属知识库

## 演示模式

公开站点没有共享模型 Key 时，会自动启用本地演示模式：

- 不需要 API Key
- 不产生模型费用
- 可以展示聊天、记忆筛选和界面交互
- 明确显示这是离线演示回复
- 用户填写自己的 Key 后可切换真实模型

## 自动化验证

```powershell
npm run test:memory
npm run eval:ai
npm run build
```

第一轮的确定性测试不需要调用 DeepSeek，因此 Token 成本为 0。真实模型评测需要使用 `--live` 并消耗用户自己的 API Key。
